# DoL-Thalia Hub

DoL-Thalia Hub 是 DoL-Thalia 的发布页面，用于查看最新版本、历史版本、在线版与已收录模组。

DoL-Thalia Hub is the release page for DoL-Thalia, including the latest version, version history, online play, and listed mods.

## 首页 / Home

首页展示当前推荐版本，并提供在线游玩与下载入口。

The home page shows the recommended version with play and download links.

## 模组 / Mods

模组页展示已收录的 `.mod.zip` 与 `.modpack` 文件，以及作者和模组仓库信息。玩家可以下载，也可以用于生成自定义 ZIP 游玩包。

The mods page lists available `.mod.zip` and `.modpack` files with author and repository information. Players may download them or use them to create a custom ZIP package.

## 历史版本 / Version History

历史版本页保留旧版本入口，方便玩家选择适合自己的版本。

The version history page keeps older releases available for players who need a specific version.

ZIP 与 APK 下载文件通过 GitHub Releases 发布，网站只保存下载链接。

ZIP and APK downloads are published through GitHub Releases. The website only stores their links.

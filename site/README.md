# DoL-Thalia Hub

DoL-Thalia Hub 是 DoL-Thalia 的发布页，用于查看最新版、历史版本、在线版入口和可选模组信息。

This hub is the release page for DoL-Thalia. It lists the latest downloads, older releases, online play, and optional mod information.

## 这是什么

DoL-Thalia Hub 不是 DoL 或汉化组官方网站，只是 DoL-Thalia 的第三方发布页面。

页面中的 ZIP 与 APK 下载通常指向本仓库的 GitHub Releases。网站本身只展示下载入口、版本说明和必要提醒。

## 怎么下载

首页会引导到最新版下载。下载前请先选择需要的组合版本，再选择 ZIP 或 APK：

- **ZIP**：解压后打开 HTML 文件游玩，适合电脑浏览器。
- **APK**：安装到 Android 设备游玩，更新前请先导出存档。
- **在线游玩**：只提供默认组合，适合快速测试。

历史版本页面会按原版游戏版本分组。需要旧版本时，先选择对应游戏版本，再选择具体组合。

## 关于模组

部分模组信息会在站点中展示，但并不是所有玩家都需要手动操作模组页面。普通玩家优先下载已经整合好的 ZIP 或 APK。

如果你看到 `.mod.zip` 或 `.modpack` 文件，它们通常是给 ModLoader 使用的模组文件；不要把完整游戏 ZIP 当作模组导入。

## 反馈顺序

使用 DoL-Thalia 遇到问题时，建议按这个顺序排查：

1. 先用汉化仓库发布的版本或汉化在线版测试。
2. 如果汉化原版也有问题，优先向汉化仓库反馈。
3. 如果只有 DoL-Thalia 有问题，再向 DoL-Thalia 反馈。
4. 如果问题来自某个可选模组或美化资源，请查看对应模组作者的说明。

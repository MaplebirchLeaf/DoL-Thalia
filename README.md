# DoL-Thalia

DoL-Thalia 是一个面向 Degrees of Lewdity 的 ModLoader 整合版本，提供可直接游玩的浏览器版本，并支持下载 ZIP 游玩包。

DoL-Thalia is a ModLoader-integrated build of Degrees of Lewdity. It provides a browser-playable version and downloadable ZIP packages.

## 在线游玩 / Play Online

在线版会在发布网站中提供。你可以直接在浏览器中打开，不需要额外安装。

The online version is provided through the release hub and can be played directly in a browser.

## 下载 / Download

发布网站会提供最新版本和历史版本下载。ZIP 游玩包适合电脑浏览器本地游玩。

The release hub provides the latest and older versions. ZIP packages are intended for local browser play.

## 模组 / Mods

DoL-Thalia 会展示已收录的模组文件。玩家可以按需下载，也可以在网站中选择模组生成自定义 ZIP 游玩包。

DoL-Thalia lists available mod files. Players may download them directly or select mods on the hub to create a custom ZIP package.

- 模组兼容性由模组本身决定，遇到问题时请优先查看对应模组说明。
- 请从可信来源下载游戏与模组文件。
